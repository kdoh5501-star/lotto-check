# 💰 백만장자 A조 로또 당첨확인

우리 로또 모임 A조가 매주 사는 402게임(134줄 × A/B/C)이 이번 주 당첨번호와 몇 개 맞았는지 자동으로 확인해 주는 무료 프로그램이에요.

## 쓰는 법

**링크를 누르기만 하면 돼요.** 설치는 필요 없어요.

👉 https://kdoh5501-star.github.io/lotto-check/

- 열면 동행복권에서 **가장 최근 회차 당첨번호를 알아서 가져와요.**
- 몇 등이 몇 게임 나왔는지, 어떤 번호가 맞았는지 바로 보여줘요.
- **◀ 이전 / 다음 ▶** 버튼으로 지난주 결과도 볼 수 있어요. (2026년 9월 제1240회부터)
- 추첨은 매주 토요일 저녁 8시 35분이고, 결과는 보통 9시쯤 나와요.

휴대폰에서는 카톡으로 받은 링크를 누르거나, 인터넷 창에서 "홈 화면에 추가"를 해두면 앱처럼 쓸 수 있어요.

## 번호를 바꾸고 싶을 때

번호는 전부 `index.html` 파일 안의 `<script type="text/plain" id="combos">` 부분에 한 줄에 한 게임씩 적혀 있어요.

```
1A    3 10 23 33 37 40
1B    3 10 23 33 37 41
```

깃허브에서 `index.html` → 연필(✏️) 버튼을 누르고 이 목록만 고친 뒤 저장하면, 1~2분 뒤 링크에 반영돼요. 새 번호를 쓰기 시작하는 회차가 바뀌면 `FIRST_EP` 숫자도 같이 바꿔주세요.

## 알아두세요

- 당첨번호는 동행복권(dhlottery.co.kr) 홈페이지에서 가져와요. 동행복권 사이트가 바뀌어서 번호를 못 가져오면 번호를 직접 넣는 칸이 나와요.
- 재미로 만든 프로그램이에요. 정확한 당첨 여부는 꼭 동행복권이나 판매점에서 한 번 더 확인하세요.
- 동행복권과는 관계없는 개인 프로그램이에요.
